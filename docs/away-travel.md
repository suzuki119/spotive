# 遠征サポート（主要機能 5）設計

参考にした画面：`遠征サポート1.png`（AWAY TRAVEL）と `遠征サポート2.png`（観戦プラン）。
デモサイトとしての実装です。交通・ホテルの金額はすべて**目安**で、実際の予約・購入はしません。

---

## 1. 何ができるか

| 画面 | ファイル | できること |
| --- | --- | --- |
| AWAY TRAVEL | `pages/travel/travel.php` | 応援チームを選ぶ → 次のアウェー戦 → 交通・ホテル・費用の目安 → 遠征中に観られる他の試合 → プランを作る |
| 観戦プラン | `pages/travel/travel-plan.php` | 作ったプランの一覧、予定表（時刻順）、購入済み・予約済みの印、プランの削除 |

入口は下のメニューの「メニュー」→「遠征」と、ホテル詳細の「遠征プランに追加」です。
画面は誰でも見られます。プランの作成・保存にはログインが必要です（Lv.1 以上）。

### 想定ユーザーの声との対応

| 声 | 対応するところ |
| --- | --- |
| 「遠征先でもう1試合観られないかな？」 | 「この遠征中に観られる試合」。会場から 50km 以内で、旅程の前日〜翌日にある試合を出し、プランに追加できる |
| 「学生だから3,000円以内で観たい」 | 費用の目安（交通・宿泊・チケット・食事ほか）を 1 人あたりで出す |

## 2. データの持ち方

**試合・チーム・会場・ホテルは、今は DB に移しません。** 地図の JS（`js/pages/map.js`）が `data/matches.json` を直接読んでいて、試合を DB に移すと影響が大きいためです。遠征のテーブルは、`favorite_teams` と同じく、JSON の id をそのまま持ちます。

| データ | 置き場所 | 備考 |
| --- | --- | --- |
| 試合 | `data/matches.json`（＋ `v_public_tournaments`） | `lib/match.php` で読む |
| チーム | `data/teams.json` | `areaId` をチームの本拠地として使う |
| 出発地の候補 | `data/areas.json` | 緯度経度は各エリアの代表地点 |
| ホテル | `data/hotels.json`（架空の仮データ） | `lib/hotel.php` で読む。機能 6 の方針に合わせ、DB には入れない |
| 交通 | データなし（距離から計算） | 下の「交通の目安の出し方」を参照 |
| **遠征プラン** | **DB：`travel_plans` / `travel_plan_items`** | ユーザーが作るデータなので DB に保存する |

### テーブル（`db/schema.sql`）

**`travel_plans`**：プラン 1 件

| カラム | 型 | 内容 |
| --- | --- | --- |
| id | BIGINT UNSIGNED | |
| user_id | BIGINT UNSIGNED | 作った人（`users.id`、削除されたら一緒に消える） |
| team_id | VARCHAR(32) | 応援するチーム（`data/teams.json` の id） |
| title | VARCHAR(150) | 「FE名古屋vs静岡観戦プラン」 |
| depart_area_id | VARCHAR(32) | 出発地（`data/areas.json` の id） |
| start_date / end_date | DATE | 旅程の初日・最終日 |
| estimated_total_yen | INT UNSIGNED | 作成した時点の費用の目安（1 人あたり） |
| created_at / updated_at | DATETIME | |

**`travel_plan_items`**：予定表のカード 1 枚（交通・試合・ホテル）

| カラム | 型 | 内容 |
| --- | --- | --- |
| id | BIGINT UNSIGNED | |
| plan_id | BIGINT UNSIGNED | `travel_plans.id`（プランを消すと一緒に消える） |
| item_type | ENUM('transport','match','hotel') | カードの種類 |
| ref_id | VARCHAR(32) NULL | 試合は `match-001` / `tournament-5`、ホテルは `hotel-001`。交通は NULL |
| title | VARCHAR(150) | 「新幹線・特急（目安）」「静岡 vs FE名古屋」「ホテル名」 |
| from_label / to_label | VARCHAR(50) NULL | 交通の出発地・到着地、試合の会場 |
| starts_at / ends_at | DATETIME | 交通は発・着、試合は開始・終了予定、ホテルはチェックイン・チェックアウト |
| price_yen | INT UNSIGNED NULL | 交通は片道、試合はチケットの最低価格、ホテルは 1 泊 |
| booking_status | ENUM('none','booked') | 「購入済み」「予約済み」の印。**ユーザーが自分で付ける**（SPOTIVE は販売しないので、本当に買ったかは分からない） |
| url | VARCHAR(500) NULL | 予約・販売サイト。仮データでは空 |

JSON が書き換わってもプランの表示が変わらないよう、名前・時刻・金額は作成した時点の値を items に写して持ちます。

**保存するのは交通・試合・ホテルの 3 種類だけです。** 「静岡に到着」「アリーナへ」「チェックアウト」の行は、表示するときに items から作ります（時刻を変えても行どうしがずれないようにするため）。

| 表示する行 | 作り方 |
| --- | --- |
| ○○を出発 / ○○に到着 | 交通の starts_at / ends_at |
| 会場へ | 試合の開始 60 分前 |
| チェックアウト | ホテルの ends_at |

## 3. 計算のしかた（`lib/travel.php`）

数字は `lib/travel.php` の先頭の定数にまとめています。変えるときはそこだけを直します。

### 遠征（トリップ）のまとめ方
- 選んだチームが**アウェー**（`awayTeamId`）の、今日以降の試合を探す
- 同じ会場で日付が連続する試合（バスケの GAME1・GAME2 など）は、1 回の遠征にまとめる
- 「日程を変更」では、これから先の遠征を選び直せる

### 交通の目安の出し方
時刻表・運賃を無料で取れる API がないため、出発地から会場までの**直線距離から計算**します。

| 直線距離 | 手段 | 所要時間 | 片道運賃 |
| --- | --- | --- | --- |
| 40km 未満 | 在来線・バス | 20 分 ＋ 1.5 分/km | 200 円 ＋ 20 円/km |
| 800km 未満 | 新幹線・特急 | 30 分 ＋ 線路距離（直線 × 1.2）を時速 200km | 1,500 円 ＋ 28 円/km（線路距離） |
| 800km 以上 | 飛行機 | 空港までの移動を含め 150 分 ＋ 時速 700km | 15,000 円 ＋ 12 円/km |

所要時間は 10 分単位、運賃は 100 円単位に丸めます。実際の運賃とは違うので、画面では必ず「目安」と表示します。

### 行き・帰り・宿泊
- **行き**：最初の試合の会場へ、試合の 120 分前に着く便。出発が 6:00 より早くなるときは、前日の 16:00 に出発して前泊する
- **帰り**：最後の試合の会場から、終了予定（競技ごとの試合時間：野球 210 分、サッカー・バスケ 120 分、バレー 150 分、その他 150 分）の 30 分後に出発。到着が 23:30 を過ぎるときは、翌日 10:00 に出発して後泊する
- **ホテル**：泊数は「行きの到着日」から「帰りの出発日」まで。遠征の本来の会場（前後に追加した試合の会場ではない）から 3km 以内の `hotels.json` から近い順に選び、無ければ「会場周辺のホテル（1 泊 9,000 円の目安）」とする。時刻が決まっていない試合は 13:00 開始とみなす

### 費用の目安（1 人あたり）
交通（往復）＋ ホテル × 泊数 ＋ チケットの最低価格の合計 ＋ 食事ほか（2,000 円 × 日数）

### この遠征中に観られる試合
旅程の前日〜翌日に、会場から 50km 以内で行われる試合（主催者が掲載した大会を含む）を出します。遠征の試合と同じ日に 3 時間以内で重なるものは除きます。追加すると、旅程・泊数・費用はそれに合わせて計算し直します。

## 4. 画面ごとの動き

### AWAY TRAVEL（`travel.php`、GET で条件を切り替える）

| パラメータ | 内容 | 省略したとき |
| --- | --- | --- |
| team | 応援チーム | お気に入りの先頭のチーム、無ければアウェー戦のある最初のチーム |
| game | 遠征の最初の試合（`match-001`） | 次のアウェー戦。ほかのチームの試合を渡すと、そのアウェー側のチームにする |
| from | 出発地（`area-23`） | チームの本拠地 |
| hotel | ホテル（`hotel-001`） | 会場に一番近いホテル |

「この条件でプランを作成」は POST（CSRF あり）。金額などは画面から受け取らず、サーバーで計算し直してから保存し、観戦プランへリダイレクトします。

### 観戦プラン（`travel-plan.php`）
- `?id=` なし：自分のプランの一覧
- `?id=` あり：予定表。他人のプランは開けない（404）
- POST：`toggle`（購入済み・予約済みの印の切り替え）、`delete`（プランの削除）
